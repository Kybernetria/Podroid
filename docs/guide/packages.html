Packages & services

Podroid now ships a deliberately minimal Alpine 3.23 direct-kernel guest. Use apk to add software to the persistent overlay when a later profile or local workflow requires it.

Package management with apk

The Alpine main and community repositories and CA certificates are configured in the image.

~# apk update
~# apk add <package>
~# apk upgrade

Reviewed explicit package set

The image build requests exactly these packages; the build verifier also inspects the resolved package database in the SquashFS:

PurposePackages
Alpine/OpenRC basealpine-base, openrc, busybox-openrc
Networkingiproute2
Public-key-only SSHdropbear, dropbear-openrc
TLS trustca-certificates

apk-tools and other essential libraries arrive only through the resolved Alpine base dependency closure.

Not bundled in the base image

Docker, Podman, LXC, container runtimes and networking stacks, X11/VNC, PulseAudio, desktop/font packages, predefined workload services, podroid-backup, and podroid-update-stats are not shipped. The inherited Android X11 screen remains during staged UI work, but the minimal guest provides no X11 or audio server.

OpenRC boot services

BusyBox init starts OpenRC as the service manager. The default runlevel contains only the preserved VM contract:

ServiceRole
podroid-migrateRuns bounded, idempotent system-image migrations before bringup.
podroid-bootstrapMounts virtual filesystems/cgroup2, prepares 9p and future TUN/FUSE prerequisites, and configures ZRAM/OOM policy.
podroid-networkUses static QEMU SLIRP addressing or bounded AVF DHCP.
podroid-resizeRelays hvc1 resize messages to the app-owned hvc0 console.
dropbearProvides public-key-only SSH; no authorized key is bundled.
podroid-vsockProvides the AVF control/forward transport and skips on QEMU.
podroid-downloadsMounts the AVF 9p-over-vsock Downloads share; QEMU 9p is mounted by bootstrap.
podroid-hostdProvides the guest-to-Android bridge on both backends.
podroid-readyEmits Starting SSH..., Almost ready..., and Ready!.

Persistent upgrades

The system lower is read-only SquashFS and user changes live on the ext4 overlay. Migration 31 removes obsolete system startup/config/helper paths from older appliance images. It does not delete old container directories, home directories, or any other data under /mnt/persist.
